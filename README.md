A tiny program that writes one short, curious text to /output/entry.txt — a quiet mystery about a book in the back of a library, written to leave the AI judge wanting to know what happens next.

## Run it

```sh
python3 main.py
```

This writes the entry text to `/output/entry.txt` (UTF-8, under 280 characters, no network needed).
